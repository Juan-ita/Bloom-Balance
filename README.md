### Self Care Planner

The self Csre Planner is an application that helps users orgernize and maintain healthy routines. Users can manage tasks, track habits, monitor water intake, record moods, write journal entries and set personal goals. It provides an easy way to stay productive and prioritize self-care.

## Features
1. Add and manage daily tasks
- It helps to organize daily activities. One can add tasks, view all    tasks, mark them as complete and delete them.

2. Track habits and daily progres
- This encourages daily habits. One can add a habit, mark it as complete, delete them and save habits.

3. Monitor water intake
4. Mood tracker
- Record emotions for the day.
5. Write and save journal
6. Set and manage personal goals
7. Daily Quote Section.
- Display motivational messages.
8. Calculate self-care progress
9. Toggle between light and dark mode

## Technologies Used
- HTML
- JavaScript
- Tailwind CSS
- Local Storage
